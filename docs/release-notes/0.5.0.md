First release of REWIND v2: an 80s/90s TV experience for a mini PC or a Raspberry Pi.

## Install

On Debian 13 (amd64) or Raspberry Pi OS Lite 64-bit (Pi 4/5), as the user who will own the TV:

```bash
wget -qO- https://github.com/GermainChavigny/rewind/releases/latest/download/install.sh | bash
```

Reboot: the TV starts on REWIND and shows a QR code to finish the setup from your phone.

## What's in it

- YouTube channels with retro logos, alarm clock, weather, TV smart plug (Shelly)
- Movies and series: search (Jackett, installed and connected by default), downloads, subtitles, Movie Advisor
- Phone settings with a setup wizard, and a virtual remote
- cage + Chromium kiosk, updates from the phone (Settings → Mise à jour)

The user interface is in French for now.
