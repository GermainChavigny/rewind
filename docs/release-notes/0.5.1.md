Fixes from the first installs. Update from the phone (Settings → Mise à jour), or run `/opt/rewind/install.sh update` on the TV.

## Fixes

- Subtitles: downloads from OpenSubtitles failed for every movie and episode without embedded subtitles. They work again.
- Settings: an API key (e.g. Groq) could be lost or swapped after removing or adding an Advisor provider or an indexer.
- Settings: the search and Movie Advisor buttons on the TV, and the channel names on the phone remote, now follow changes at once (no page refresh).
- Install: a system without Python gets it installed first, instead of the installer stopping.

## New

- Alarm: the chime can start after a delay ("La sonnerie démarre après").
- Movie Advisor: 2010s, 2020s and recent (last two years) release periods.
- Series: the size of each downloaded episode.
- Phone remote: hold the volume or brightness key to repeat it.
- The "Film prêt" announcement is now off by default (Settings → Vidéothèque to turn it on).
